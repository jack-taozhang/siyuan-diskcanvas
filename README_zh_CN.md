# DiskCanvas 盘绘

> 把网盘文件和思源笔记铺到一张无限画布上，用连线把思路串起来。

## 它解决什么问题

资料通常散在两处：**NAS 上的文件**（设计稿、文档、图纸）和**思源里的笔记**。
想把它们的关系理清时，要么反复切窗口，要么在脑子里硬记 —— 很想「摊开来看」。

这个插件给思源加一张无限画布：

- **网盘文件**直接拖上画布，图片 / PDF / Office / 图纸各走各自的预览通道
- **思源笔记**（文档 / 块）与**思源资源**（assets 里的图片、PDF…）也拖上画布
- 两者之间**拉一根线**，关系就落下来了

底层用开放的 `.canvas`（JSON Canvas）格式，文件是纯 JSON，看得懂、搬得走。

## 卡片类型

卡片**抬头显示类型名**（如「网盘文件」），右侧徽标显示细分类型（`PDF` / `DWG` / `DOCUMENT`）。

| 卡片 | 抬头 | 内容 | 双击行为 |
| --- | --- | --- | --- |
| **文本** | 文本 | 直接写在画布上的 Markdown | 进入编辑 |
| **网盘文件** | 网盘文件 | NebulaDisk 上的文件 | 用对应预览器打开 ※ |
| **思源笔记** | 思源笔记 | 思源文档 | 跳回思源定位 |
| **思源块** | 思源块 | 思源里的块 | 跳回思源定位 |
| **内部文件** | 内部文件 | 思源 assets 里的资源（图片 / PDF…） | 跳到它所在的文档与块 |
| **链接** | — | 网页地址 | 浏览器打开 |
| **分组** | — | 把相关卡片框在一起 | 折叠 / 展开 |

> ※ 在**独立网页**里编辑时，双击网盘卡片改为**用浏览器单独打开该网盘文件**
> （见下文「独立网页编辑」）。其余卡片行为一致。

> 笔记卡片默认只显示**标题 + 大纲**（不铺全文），一眼看清结构。

## 连线

- 从卡片四边锚点拖拽创建连线
- 可加文字标签（"参考"、"导致"、"属于"）
- 箭头：无 / 单向 / 双向
- 拖端点到别的卡片可改接；拖到空白处删除
- **线型支持实线 / 虚线**；颜色取自 12 色调色板或自定义取色器

## 画布操作

| 操作 | 说明 |
| --- | --- |
| 左键单击 | 选中 |
| `Ctrl` / `Shift` + 单击 | 多选 |
| 拖拽卡片 | 移动 |
| 拖拽边缘 / 角落 | 调整大小 |
| 拖拽锚点 | 创建连线 |
| 框选空白 | 批量选中 |
| **右键拖拽** | **平移视图** |
| **鼠标中键双击** | **适应内容（把所有节点缩放到铺满视口）** |
| 滚轮 | 以光标为中心缩放（0.1x ~ 2.5x） |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 撤销 / 重做 |

- 画布**默认自动保存**
- 工具栏有 **刷新**（从磁盘重新载入当前画布）与 **导出 PNG**（可选范围与背景色）

### 网格线

工具栏「调色板」右边的 **网格** 按钮可以即时调整画布的参考网格：

| 项 | 可选值 |
| --- | --- |
| 样式 | 不显示 / 点阵 / 方格 / 横线 / 纵线 |
| 间距 | 16 / 24 / 32 / 48 像素（世界坐标，设置面板里可填 8–64 的任意值） |
| 吸附到网格 | 开 / 关（拖动卡片、新建卡片、**调整卡片大小时**都会对齐到网格线） |

- 网格是**世界坐标**的：缩放时格子跟着缩放，平移时跟着走 —— 它是一把尺子，不是一张贴纸
- 吸附吸的是**正在拖的那条边/那个落点**（所以卡片本来不在格上时也吸得上去）；
  调整大小时仍然守住卡片的最小尺寸，且**对齐辅助线优先于网格**（8px 内以辅助线为准）
- 缩放太小（格子挤到 4px 以下）时会**自动隐藏**，避免糊成一片灰，弹层里会说明原因
- 网格线颜色跟随主题，深浅色模式自动适配
- **嵌入到笔记里的画布预览不显示网格** —— 那是阅读场景，网格会跟笔记的行距抢视觉
- 同样可以在 **设置 → 插件 → DiskCanvas 盘绘** 里改

## 独立网页编辑

工具栏最右侧（**帮助按钮右边**）有一个 **在独立网页中打开** 按钮：
把当前画布文件单独放进一个浏览器页签里编辑，**不带思源的界面**。

- 地址形如 `/plugins/siyuan-diskcanvas/standalone.html?path=<画布路径>`
- **渲染与思源里完全一致** —— 不是"另一套简化渲染器"，而是**同一份组件代码**
  （思源页签、嵌入预览、独立页三者共用同一个 `CanvasWorkspace`）。
  独立页启动时会向内核取来思源当前的**基座样式 / 主题样式 / 已启用的 CSS 代码片段**，
  并沿用同一份插件设置，所以配色、字体、卡片细节都对得上。
- 编辑、保存、撤销、缩放、连线、调色板、快捷键**全部可用**，写的是同一个 `.canvas` 文件
- 独立页里**双击网盘卡片** = 用**单独网页**打开该网盘文件
  （地址由网盘侧按文件类型给出：原生类型走直链、Office/压缩包走在线预览、CAD 走图纸查看器）

> 需要网盘插件 **1.0.4 及以上**（`webUrl` 契约方法）。版本过低时会明确提示，不会静默失败。

## 与网盘插件的关系

**画布不单独配置网盘连接。**

网盘插件 `siyuan-nebuladisk` 会通过 `window.__nebuladiskPlugin.external` 暴露一份
对外契约（`listMounts` / `list` / `stat` / `previewUrl` …）。画布消费这份契约：

- 网盘插件登录好了，画布就能用 —— **不需要在画布设置里再填一遍地址和账号**
- 预览地址一律由网盘侧构造，画布只转发（内部地址与签名逻辑不会泄漏到画布侧）

> 因此本插件的设置面板里**没有**网盘连接项；网盘不可用时会明确提示"未检测到网盘插件"。

## 从网盘拖入画布

在网盘插件的文件树里**直接把文件拖到画布上**即可创建网盘文件卡片 ——
拖拽协议是网盘插件定义的 `application/x-nebuladisk-embed`，两个插件各自放行自己不认识
的拖拽，互不干扰。

## 内置能力

- **搜索高亮**：思源全局搜索命中的文字，在画布卡片上一并高亮
- **嵌入预览**：把 `.canvas` 作为**只读预览块**嵌进笔记正文
  （保留缩放与右键平移，不参与任何编辑）
- **调色板**：每套主题 12 色，另可自定义取色
- **线型**：卡片 / 分组 / 连线均支持实线↔虚线

## 开发

```bash
npm install
npm run build              # 插件本体 + 独立网页（产物输出到 ./dist）
npm run build:plugin       # 只构建插件本体
npm run build:standalone   # 只构建独立网页（standalone.html / .js / .css）
npm test                   # 单元测试（vitest）
npm run verify             # 静态契约检查 + 构建 + 产物闸门 + 端到端
npm run check:template     # 只跑「模板/脚本里没有来源的标识符」闸门
```

> 独立网页与插件本体是**两次构建、同一个输出目录**：
> `build:plugin` 先清空 dist 再写 `index.js`，`build:standalone` 只往里加文件。
> 顺序不能反 —— `check:standalone` 会对此兜底。
